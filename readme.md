# ParkingMate
Parking mate is a solution to the problems a Delivery Station of a Last Mile company might be going through based on my understanding and experience. The solution focuses on resolving issues surrounding  
* Driver Identification and Check-in/Check-Out
* Package Hand-off
* Mapping the parking (hate not knowing where a route is parked at)
* Report Generation
